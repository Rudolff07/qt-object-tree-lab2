## Описание проекта
Данный проект демонстрирует работу с деревом объектов в Qt (`QObject`). 
В программе реализовано:
- Создание виджетов с явным указанием родителя (`parent`).
- Отслеживание создания и уничтожения объектов через переопределенные деструкторы и `qDebug()`.
- Демонстрация автоматического удаления дочерних виджетов при удалении родителя.
- Исследование поведения метода `setParent()` при смене владельца (включая отвязку через `nullptr`).
- Безопасное удаление объектов с помощью `deleteLater()` и защита от висячих указателей через `QPointer`.

## Инструкция по сборке и запуску
1. Откройте файл `ObjectTreeDemo.pro` в **Qt Creator**.
2. Выполните команду **Сборка -> Выполнить qmake** (Run qmake).
3. Нажмите **Сборка -> Пересобрать проект** (Rebuild).
4. Запустите приложение (зеленая стрелка `Run`).
5. Для просмотра логов создания и удаления объектов откройте вкладку **Application Output** (Вывод приложения) в нижней панели Qt Creator.

## Демонстрация ошибок
В файле `main.cpp` в функции `main` закомментированы вызовы функций `demoError1()`, `demoError2()` и `demoError3()`. 
Раскомментируйте нужную строку и запустите проект, чтобы увидеть:
1. Падение программы при смешивании стекового и кучного создания.
2. Утечку памяти при `setParent(nullptr)`.
3. Визуальную ошибку при смене родителя без обновления `Layout`.
